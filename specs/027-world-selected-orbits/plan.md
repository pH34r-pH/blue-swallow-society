# Plan

Use the existing VM pg pool in an isolated world-orbit-postgres-store module and migration 0008; no observation/entity joins. Atomic row-locked claim commits a pessimistic stop latch before network, and a matching receipt may clear it only after validated success. Database time and attempt token prevent reset/worker races. PostgreSQL unavailable/migration absent fails closed without public request. Explicit host flag starts the optional worker; default remains off.

Vendor pinned mature satellite.js SGP4 pure-JS bundle and Cesium 1.145.0 with licenses/provenance. Lazy fetch/import the Cesium ES module through existing private asset authorization; nested fixed-manifest workers/assets use an owner-cookie-gated route. Disable all Cesium external defaults and use local Natural Earth land only. Standard TEME-to-pseudo-fixed conversion uses the same Julian date, with documented UT1=UTC approximation. Render ellipsoid height rather than a ground point.

Public snapshots expose only selected GP metadata/elements and source status. Existing World Owner.Read wrapper forwards no coordinates. Reset is a maintenance CLI using canonical exact-owner World.Manage validation, failure ID and reason; no new OAuth registrations or consent flow. Proposed scope must be provisioned only during an approved future activation.
