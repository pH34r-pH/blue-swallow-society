# Private bird-history import

Status: foundation in progress; issue #122 under Society vNext #85.

An owner can import a supported personal export privately, review added,
changed, duplicate and rejected records, and explicitly approve a sanitized
public projection. Imports default to draft. A password viewer cannot import,
publish or read private locations, notes or account details. A partial export
never implies deletion; full reconciliation and unpublication require explicit
review and recovery. Presence-only and unknown counts remain distinct from exact
counts. A recognition suggestion alone is not a confirmed observation.

The actual owner's export and saved-Merlin coverage remain unverified. Do not
claim automated personal-history access without a supported provider contract
and authorized end-to-end evidence. No Cornell password or undocumented mobile
endpoint is required.
