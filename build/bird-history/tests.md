# Bird-history independent test contract

Cases state spec-level behavior. Most adopt the existing Node tests, which cover the draft-first import; the new file `tests/bird-history-spec.test.mjs` adds cases for limits and boundaries those tests do not pin down. The new cases were written from the specification after characterization, and a fault-injection spot check confirmed they fail when the behavior they cover is broken. A case passes when every listed test passes.

| Case | Requirements | Stimulus | Expected observable result | Executable tests |
| --- | --- | --- | --- | --- |
| BH-001 | BH-FR-001, BH-SC-001 | Preview and save with no credential, a viewer credential, conflicting credentials and a non-owner authentication mode. | Each is denied before the body is read or storage is opened. | `tests/bird-import-preview-api.test.mjs::only an owner can preview and denial happens before private body access`; `tests/bird-import-commit-api.test.mjs::viewer, cross-origin, malformed and changed previews fail before writing`; `tests/bird-import-preview-api.test.mjs::origin, method, content type, request shape, encoding and size fail closed with redacted errors`; `tests/bird-history-spec.test.mjs::BH-FR-001 save denies absent and viewer credentials before reading its body` |
| BH-002 | BH-FR-002, BH-SC-001 | Send the wrong method, a query string, a wrong origin and a wrong content type. | 405, 405, 403 and 415 with fixed error codes. | `tests/bird-import-preview-api.test.mjs::origin, method, content type, request shape, encoding and size fail closed with redacted errors`; `tests/bird-import-commit-api.test.mjs::viewer, cross-origin, malformed and changed previews fail before writing` |
